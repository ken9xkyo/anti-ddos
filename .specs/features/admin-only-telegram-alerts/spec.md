# Feature Specification: Admin-Only Telegram Alerts

This document specifies the requirements and specifications for redesigning the Telegram alert feature to be exclusive to the system administrator.

## Requirements

### REQ-01: Admin-Only Configuration Access
- **Description:** Only users with `RoleAdmin` (Platform Administrator) are permitted to view, update, or test the Telegram integration configuration.
- **API Access Rules:**
  - `GET /v1/telegram/config`: Must return `403 Forbidden` if the authenticated user is not an admin.
  - `POST /v1/telegram/config`: Must return `403 Forbidden` if the authenticated user is not an admin.
  - `POST /v1/telegram/test`: Must return `403 Forbidden` if the authenticated user is not an admin.
- **Traceability:** Maps to the API handlers in `internal/control/alert_handlers.go`.

### REQ-02: Global Admin-Owned Alert Delivery
- **Description:** The system allows only 1 active admin. All Telegram alert deliveries (whether generated by system events or tenant-specific user actions) must be routed through the admin's Telegram configuration.
- **Behavior:**
  - Alert delivery (`deliverAlert`) must query the active admin's `telegram_configs` record (where `tc.id = 1` and `u.role = 'admin' AND u.status = 'active'`) by running an unscoped database transaction.
  - Alert rate limits and templates (`alertPolicy`) must also query the active admin's `alert_policies` table record in an unscoped manner.
- **Traceability:** Maps to the core delivery and policy lookup logic in `internal/control/alert.go`.

### REQ-03: Dashboard UI Adaptation
- **Description:** The frontend dashboard must hide configuration elements from regular users and avoid unauthorized requests.
- **Behavior:**
  - When loading the dashboard data, the client-side app must only fetch `/v1/telegram/config` if the logged-in user is an admin. For normal users, it resolves a default disabled configuration.
  - The `IncidentsView` component must hide the "Telegram Channel" panel for non-admin users.
  - The "Telegram configuration changes require admin access" messaging must be displayed correctly when applicable.
- **Traceability:** Maps to `web/dashboard/src/api.ts`, `web/dashboard/src/views/IncidentsView.tsx`, and `web/dashboard/src/DashboardShell.tsx`.
